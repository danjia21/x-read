# Technical Reading Journal

This directory contains close readings, fact-checking, and extended analysis of technical articles.

The default format is “original text plus inline annotations.” Each entry preserves the article's narrative order and adds relevant background, concept explanations, fact-checking, or evidence boundaries directly after the corresponding passage. Original text and added commentary are always clearly distinguished.

- `entries/YYYY/`: notes archived by reading year
- `catalog.md`: an index of all entries by topic and date

Example prompt:

> Use $technical-reading-journal to digest this technical article and add it to my reading journal: [URL]
