# Technical Reading Journal

This directory contains concise reading guides, fact-checking, and inline notes for technical articles. The original article remains on its publisher's website; the x-read browser extension places each note beside the relevant source passage.

Entries in `entries/YYYY/` store source metadata, original journal notes, and short placement anchors. The site derives its list and topic index directly from entry metadata.

Example prompt:

> Use $technical-reading-journal to digest this technical article and add it to my reading journal: [URL]
