# Reading journal

Treat a standalone URL or Markdown link to a technical article, paper, research post, or technical repository as a request to create or update a journal entry in `reading-journal/`. Follow explicit requests about links as written.

Read and apply the [technical reading journal skill](.agents/skills/technical-reading-journal/SKILL.md) even if it is absent from the session's skill list. The URL authorizes saving, committing, and publishing the journal update as the skill specifies.
